K3K3ride × Moolre Payment Flow
Student Login Phone + OTP (SMS)
Request Ride Web or USSD
Route Matching Algorithm pairs rider
Trip in Progress SMS updates both
Trip Complete Fare confirmed
MoMo Collection Passenger pays GHS
K3K3 Receives Deducts 15% commission
Rider Gets Paid 85% via Disbursement

Moolre API Usage Breakdown

SMS API
  • ✔ OTP delivery on login
  • ✔ Booking confirmation (passenger + rider)
  • ✔ Trip status updates
  • ✔ Payment receipt to passenger
  • ✔ Payout confirmation to rider
  • ✔ Trip cancellation alerts
USSD API
  • ✔ Passenger: Request a ride
  • ✔ Passenger: Pay for ride
  • ✔ Passenger: Check ride status
  • ✔ Rider: Go online / offline
  • ✔ Rider: Check earnings
Collections API
  • ✔ Initiate MoMo prompt (passenger)
  • ✔ Receive payment confirmation webhook
  • ✔ Poll collection status
Disbursements API
  • ✔ Auto-pay rider earnings (85%)
  • ✔ Triggered by collection webhook
  • ✔ Poll disbursement status
  • ✔ Commission: 15% retained by K3K3
